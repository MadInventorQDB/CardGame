# Next Blackjack

Next Blackjack is a twist on classic blackjack with a two-minute time loop. Your goal is to cash out with the highest score before the loop resets, and the only thing you keep between loops is your memory of the cards. It was created in Unity for the [GMTK Game Jam 2025](https://itch.io/jam/gmtk-2025).

Play or download the jam submission on itch.io:
[Next Blackjack by Mr. Awesome Bruce](https://mr-awesome-bruce.itch.io/next-blackjack).
